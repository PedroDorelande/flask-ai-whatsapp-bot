📖 Tutorial: Configurar o WAHA

Passo a Passo

Siga estes passos para configurar o WAHA corretamente. Isso so precisa ser feito 1 vez na primeira instalacao, ou quando trocar de numero.

1 Acessar o Painel do WAHA

Abra o painel do WAHA no navegador. O login e a senha estao no seu arquivo .env:

📍 Link:
👤 Usuario: {{ waha_user }}
🔑 Senha: {{ waha_pass }}
🔗 Abrir Painel do WAHA
2 Configurar o Webhook (Receber Mensagens)

No painel do WAHA, va na sessao "default" e configure o webhook para que as mensagens cheguem no bot:

📌 Webhook URL:
📋 copiar
📌 Events (marque estes):
message message.any session.status
3 Conectar o WhatsApp (QR Code)

No painel do WAHA, clique em "Start" na sessao "default". O QR Code vai aparecer. Depois:

  1. No celular, abra o WhatsApp
  2. Va em Configuracoes → Aparelhos Conectados
  3. Toque em "Conectar um Aparelho"
  4. Escaneie o QR Code que apareceu no painel do WAHA
  5. Aguarde o status mudar para "WORKING"
4 Trocar de Numero

Para trocar o numero do WhatsApp conectado:

  1. Acesse o painel do WAHA (Passo 1)
  2. Na sessao "default", clique em "Logout" ou "Stop"
  3. Depois clique em "Start" para gerar um novo QR Code
  4. Escaneie com o novo celular/numero
  5. O webhook ja vai estar configurado — nao precisa refazer!
